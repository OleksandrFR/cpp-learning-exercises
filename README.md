# C++ Learning Exercises

A small collection of **educational C++ exercises** written while learning the language. These are beginner practice programs, not production software.

## Exercises

- `even.cpp` — check whether an integer is even.
- `getmax.cpp` — compare two integers with a function.
- `enum.cpp` — use an `enum class` and `switch` for a difficulty choice.
- `links.cpp` — demonstrate changing a value through a pointer and a reference.
- `printLonger.cpp` — compare two words by length.
- `olds.cpp` — store student records in a struct array and find the oldest student.

## Build and run

Each file is a separate program with its own `main()` function. Compile one at a time with a C++ compiler, for example:

```sh
g++ -std=c++17 learning-exercises/even.cpp -o even
./even
```

The programs are intentionally simple and meant for learning and experimentation.
